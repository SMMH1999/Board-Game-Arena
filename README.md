# دستیار اسپلندور برای Board Game Arena

افزونهٔ Chrome میز اسپلندور کلاسیک را از روی اطلاعات قابل‌مشاهده می‌خواند، در نوبت بازیکن حرکت پیشنهاد می‌دهد و تاریخچهٔ بازی را محلی ذخیره می‌کند. انتخاب و اجرای حرکت در اختیار بازیکن است.

## نصب

مخزن را دریافت و از حالت فشرده خارج کن. در `chrome://extensions` گزینهٔ **Developer mode** را فعال کن، **Load unpacked** را بزن و پوشهٔ `splendor-reader` را انتخاب کن. روی میز بازی افزونه را باز کن. برای ثبت خودکار، یک بار پوشهٔ آرشیو را در تنظیمات انتخاب کن.

## راهبرد و آزمون‌ها

روش پیش‌فرض «اقتصاد بهینه» است. مشخصات نسخه‌دار، قواعد و سناریوهای پذیرش کنار کد منتشر می‌شوند. [فایل راهبرد](splendor-reader/strategies/splendor_strategy_codex.json) · [راهنمای استفاده و ساختار گزارش](splendor-reader/README.md)

برای اجرای آزمون‌ها از ریشهٔ مخزن با Node.js نسخهٔ ۲۲ یا جدیدتر این دستور را اجرا کن.

```sh
node --test splendor-reader/tests/*.test.js
```

برای بازپخش نوبت‌های ثبت‌شده با موتور فعلی، `node tools/replay.cjs game.json` را اجرا کن. برای آرشیوهای قدیمی که شناسهٔ بازیکن محلی ندارند، آن شناسه را به‌عنوان آرگومان دوم بده.
