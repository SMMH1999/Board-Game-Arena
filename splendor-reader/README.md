# خواندن میز اسپلندور

1. مخزن را دانلود کن و فایل ZIP را باز کن.
2. در Chrome به `chrome://extensions` برو و **Developer mode** را روشن کن.
3. روی **Load unpacked** بزن و پوشهٔ `splendor-reader` را انتخاب کن.
4. میز اسپلندور یا بازپخش آن را در Board Game Arena باز کن. از منوی افزونه‌ها، **Splendor Table Reader** را باز کن و «خواندن میز» را بزن.
5. برای ذخیرهٔ یک نسخه روی دستگاه، «ذخیرهٔ JSON» را بزن.

افزونه هنگام کلیک از تب فعال فقط متن و اطلاعات چیدمان عناصر گرافیکی نمایش‌داده‌شده در بخش میز را می‌خواند. پیش‌نمایش تا زمان باز بودن پنجرهٔ افزونه در حافظه می‌ماند. خروجی JSON ممکن است متن قابل‌مشاهدهٔ میز را شامل شود. افزونه درخواست شبکه، کلیک روی میز یا دسترسی به داده‌های داخلی جاوااسکریپت صفحه ندارد.

خروجی این نسخه یک نمای خام از صفحه است. کارت‌ها و ژتون‌هایی که با تصویر نمایش داده می‌شوند ممکن است فقط با موقعیت عنصر و موقعیت پس‌زمینه ثبت شوند و هنوز به نوع کارت، رنگ یا تعداد تبدیل نمی‌شوند.


در صفحهٔ آموزش هم اگر میز داخل قاب Archive باشد، افزونه آن را با دسترسی همین تب می‌خواند، مشروط به اینکه مرورگر اجازهٔ خواندن سند داخل قاب را بدهد. اگر قاب هنوز بارگذاری نشده باشد، پس از نمایش میز دوباره «خواندن میز» را بزن. برای اعمال نسخهٔ جدید پس از جایگزینی فایل‌ها، در `chrome://extensions` روی **Reload** افزونه بزن.
